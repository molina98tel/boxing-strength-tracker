# Boxing Strength Tracker

PWA móvil para registrar las 3 sesiones de fuerza complementarias al boxeo.

## Incluye
- Rutinas A/B/C precargadas.
- Peso, repeticiones y RIR por serie.
- Temporizador de descanso.
- Historial local.
- Mejor carga registrada por ejercicio.
- RPE de pesas, sensación del boxeo y notas.
- Instalación como PWA.
- Funciona sin backend y puede funcionar offline después de la primera carga.

## Privacidad
Los entrenamientos se guardan en `localStorage` del dispositivo. No se envían al repositorio de GitHub ni a ningún servidor.

## GitHub Pages
Este repositorio está preparado para desplegarse como sitio estático. En GitHub: Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
